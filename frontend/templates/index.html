How It Works

Each question follows the same path from your keyboard to a worked answer.

  1. 1

    User

    You type a question in plain words, such as "Solve x^2 - 5x + 6 = 0".

  2. 2

    Web Interface

    The page in your browser sends the question to the SciSolve server. Nothing is saved after you close the page.

  3. 3

    Input Normalization

    The text is tidied up: extra spaces are removed and symbols like × ÷ − ² are converted into forms the math libraries understand.

  4. 4

    Problem/Intent Detection

    SciSolve works out what you are asking for, such as solving, simplifying or plotting, using fixed rules inside the module you picked.

  5. 5

    Scientific Computing Module

    The module for your subject (Algebra, Statistics, Matrices, Numerical Methods, Scientific Formulas or Graphing) takes over the problem.

  6. 6

    SymPy / NumPy / Matplotlib

    These Python libraries do the real work: SymPy for exact algebra, NumPy for numbers and arrays, Matplotlib for drawing graphs.

  7. 7

    Step-by-Step Result

    The module returns the final answer together with the steps that led to it, and a graph when one is needed.

  8. 8

    User

    The result appears in the chat, ready to read, check and learn from.

Current build

The interface, input normalization and module routing are working. Intent detection and the calculations are being added one module at a time, so until a module is finished it tells you so instead of guessing.

About SciSolve

SciSolve is a Python-based Scientific Computing Assistant designed to provide conversational access to mathematical and scientific-computing tools.

Technologies

  • Python
  • Flask
  • SymPy
  • NumPy
  • Matplotlib
  • HTML / CSS / JavaScript

SciSolve does not use an AI language model. It reads your question with fixed rules and computes the answer with standard scientific libraries, so the same question always gives the same result.
